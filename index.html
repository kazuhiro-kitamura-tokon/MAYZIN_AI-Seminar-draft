Section 01

お打ち合わせで確認した現状と課題 2026年6月5日 商談にて

1

シャドウAIの蔓延

採用チーム内で個人の無料／有料プランが混在。4〜5名が個人課金しているが、ツールもプランもバラバラの状態。情報セキュリティ上のリスクが放置されている。

2

AI活用レベルのばらつき

黄海様個人はスライド作成時間の大幅短縮など高い活用水準に達しているが、チーム全体（約14名）としては底上げが必要。

3

法人プラン未導入

法人プラン（ChatGPT Business等）が未導入のため、学習オプトアウトの保証がなく、組織的なコラボレーション機能も活用できていない。

4

AI推進を牽引する人材の不在

セキュリティ点検やAI活用推進を専任で担える「突き抜けた人材」が社内にいない。環境変化のスピードに対し、体制整備が追いついていない。

Section 03

新入社員 / 初級者

B｜AI×ビジネス基礎スキル学習

Section 04

施策② AI推進担当 育成プラン精鋭1名を「社内で最もAIを使いこなす人材」に

商談でお話しした「突き抜けた人材を1人つくる」を実現する個別指導プログラムです。
全6回の1対1セッションで、プロンプト技術からコーディングAI活用・業務自動化まで一気に引き上げ、
社内AI推進を自走できるキーパーソンを育成します。

Session 1 ─ メタプロンプト習得

「AIへの問いかけ」を根本から変える

CRAFTフレームからPACTフレームへの進化。コンテキストエンジニアリングの基本思想を理解し、AIの出力品質を劇的に変えるメタプロンプト技術を体得する。

Session 2 ─ バイブコーディング入門

自然言語だけで業務ツールをつくる

コードを書かずにAIと対話しながらアプリやツールを開発する「バイブコーディング」を実践。実際の業務課題（履歴書作成の自動化等）を題材に、即戦力スキルを獲得。

Session 3 ─ コーディングAI活用

Claude Code / Codex を実務に組み込む

ターミナルから直接AIに指示を出すClaude Codeや、OpenAI Codexなどのコーディングエージェントの使い分けと実践。反復作業の自動化、データ処理パイプラインの構築を体験。

Session 4 ─ GitHub ＋ 開発ワークフロー

AIと協働する開発基盤を整える

GitHubの基本操作からブランチ戦略まで。AIが生成したコードのバージョン管理、チームでの共有・レビュー体制を構築。ノーコード出身でも「つくったものを安全に管理する」力を身につける。

Session 5 ─ ハーネスエンジニアリング

AIが最大限に力を発揮できる「環境」を設計する

プロンプトだけでなく、AIに渡すコンテキスト・ナレッジ・ツール群を設計する「ハーネスエンジニアリング」の考え方を習得。社内業務に最適化されたAI活用環境を自ら構築できるようになる。

Session 6 ─ 学習習慣 ＋ 自走体制

AI進化に追従し続ける「学び方」を手に入れる

AIの技術進化は速い。新モデル・新機能のキャッチアップ方法、情報ソースの選定、実験→検証→業務適用のサイクルを確立。社内へ知見を展開する研修設計・浸透戦略まで含めて、完全な自走体制を構築する。

Section 05

法人プラン導入の必要性なぜ今すぐ切り替えるべきなのか

個人プランのままでは、情報漏洩リスクを防げません

無料・個人プランのAIは、入力データが学習に使用される可能性があります。
採用業務では個人情報を扱う以上、「入れるな」では防げない現実に対し、
仕組みとして守る体制が不可欠です。

学習オプトアウト保証

法人プランは入力データの学習不使用を明言。個人情報を扱う業務でも安心。

チームコラボレーション

GPTsの共有、ワークフロー連携、チーム全体でのナレッジ蓄積が可能に。

利用状況の可視化

誰がどれだけ活用しているか管理画面で把握。トークン消費量によるKPI管理も実現。

個人プラン（現状） 法人プラン（推奨）
データの学習利用 学習される可能性あり 学習に使用されない
チーム共有機能 なし（個人で完結） GPTs共有・ワークフロー
利用状況管理 不可（誰が何を使っているか不明） 管理画面で一元管理
パーソナライズ 個人メモリ利用可 個人メモリは制限あり ※
最新機能アクセス プランにより制限 Codex・エージェント等
※ 法人プランでもカスタムGPTによる業務特化のパーソナライズは十分に可能です。
※ 個人の有料プランは別途維持し、業務用と個人用を分離する運用を推奨します。

Section 07

推奨スケジュール最短で組織のAI活用体制を整える

Phase 1

法人プラン導入

即時〜2週間

Phase 2

全体研修（D→B）

導入後 2〜4週間

Phase 3

育成プラン開始

研修後〜 月1回×6

Phase 4

自走体制へ

約6ヶ月後〜

Phase 1：法人プラン導入

セキュリティリスク回避のため最優先で実施。経営陣への説明資料はTOKON側でサポートします。現在の個人プラン利用者の移行もご支援します。

Phase 2：全体研修

法人プラン導入後、まずD（リスク管理＆ガバナンス）で社内ルールを策定。その後B（ビジネス基礎）で全員の実務活用をスタートさせます。

Phase 3：育成プラン

全体研修と並行して、選抜1名の個別指導を月1回ペースで開始。メタプロンプト・バイブコーディング・Claude Code / Codex・GitHub・ハーネスエンジニアリングを段階的に習得していきます。

Phase 4：自走体制

育成した推進担当が社内のAI活用を牽引。トークン消費量等のKPIで活用度を測定しながら、継続的に改善サイクルを回せる体制を構築します。
